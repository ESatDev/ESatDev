### 🚀 Proyectos Destacados

#### 🚌 **BondiHora** — *Plataforma de Horarios y Recorridos de Colectivos*
> **Proyecto Universitario | Web App**

Solución web integral diseñada para optimizar la consulta de información sobre el transporte público interurbano en la región del Valle de Uco y Mendoza (Tupungato, Tunuyán, Mendoza Capital, Eugenio Bustos, entre otros).

* **Aspectos clave y funcionalidad:**
  * **Visualización en Tiempo Real:** Consulta dinámica de próximas salidas, frecuencias y tipos de servicio (Directo, Diferencial, Expreso).
  * **Transparencia en Viajes:** Cálculo automático de tarifas actualizadas y estimación de tiempo de recorrido.
  * **Geolocalización Interactiva:** Integración con mapas (*Leaflet / OpenStreetMap*) para la ubicación precisa de terminales y paradas clave.
  * **UX/UI Centrada en el Usuario:** Implementación de modo oscuro, widget de clima regional en tiempo real y selector de accesibilidad.
* **Stack Tecnológico:** `JavaScript`, `HTML5`, `CSS3`, `Leaflet API`, `Vercel`.
