## 🚀 Proyectos Destacados

### 🚌 BondiHora – Horarios de Colectivos (Proyecto Universitario)
Plataforma web interactiva desarrollada para facilitar la consulta de horarios, frecuencias, tarifas y recorridos del transporte público de colectivos en el Valle de Uco y Mendoza (Tupungato, Tunuyán, Mendoza Capital, Eugenio Bustos, entre otros)[cite: 1, 2].

- **Características clave:**
  - Consulta interactiva de salidas en tiempo real, próximas frecuencias y opciones por tipo de servicio (Directo, Diferencial, Expreso)[cite: 1].
  - Cálculo de precios por trayecto y estimación de duración de viaje[cite: 1].
  - Integración de mapas interactivos (*OpenStreetMap / Leaflet*) para la visualización y geolocalización de terminales y paradas[cite: 2].
  - Interfaz moderna y adaptativa con soporte para modo oscuro, clima en tiempo real y selector de accesibilidad[cite: 1].
- **Tecnologías utilizadas:** JavaScript, HTML5, CSS3, OpenStreetMap/Leaflet, Vercel[cite: 1, 2].
